# Phase 1 實作計畫

**Goal:** 完成 SPEC.md 的 Docker 階段，供使用者自行驗收後停下。

**Architecture:** tool-simulator 將機台狀態寫入 Redis hash；tool-api 提供 REST、metrics 與單一靜態看板。以 Compose 啟動三個容器，Redis 失敗時顯示區域錯誤並持續重試。

**Tech Stack:** Python 3.12、FastAPI、uvicorn、redis-py、prometheus_client、pytest、fakeredis、Docker Compose、GNU Make。
